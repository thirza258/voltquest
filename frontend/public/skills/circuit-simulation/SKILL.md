# Circuit Simulation & PCB Design Skill

This skill enables agents to inspect, simulate, and modify circuits and microcontroller firmware on VoltQuest (`pcb.nevatal.id`).

## Capabilities

- Breadboard circuit topology analysis
- Pinout and netlist verification (Arduino Uno/Nano, ESP32, Raspberry Pi GPIO)
- Component parameter calculation (resistor dividers, RC filters, logic levels)
- PCB routing rule checks and schematic validation
