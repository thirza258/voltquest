# VoltQuest — Learn Electronics by Playing

VoltQuest is an interactive educational workspace and circuit playground designed to teach electronics, printed circuit board (PCB) design, embedded programming, and computer architecture through hands-on simulation and guided experimentation.

## Core Learning Tracks & Modules

- **Circuit Simulation & Electronics**: Interactive breadboard modeling, analog and digital components, Ohm's law, filters, transistors, and power regulation.
- **PCB Design & Hardware Prototyping**: Schematic capture, PCB layout rules, trace routing, component footprints, bill of materials (BOM), and Gerber file generation.
- **Microcontrollers & Embedded Systems**: Runnable tutorials for Arduino Uno/Nano, ESP32/ESP32-S3, and Raspberry Pi GPIO in C++ and Python.
- **Computer Architecture & Assembly**: Logic gates, Boolean algebra, adders, multiplexers, ALUs, memory latches, and an interactive 4-bit CPU sandbox.
- **High-Performance Computing (HPC)**: C17/C++17 performance engineering, SIMD vectorization, cache tiling, OpenMP multithreading, and MPI distributed stencil algorithms.
- **Cybersecurity in Hardware & IoT**: Embedded communication vulnerabilities, protocol fuzzing, secure boot principles, and firmware defense mechanisms.
- **Computer Vision & OpenCV**: Twelve courses running real OpenCV 4.12 in the browser: thresholds and color masks, morphology, contours, histograms and Otsu, perspective correction, Hough lines and circles, template matching, vision-transformer attention, and an IoT/drone/robot integration capstone.
- **Computer Networking & Network Simulator**: Ten courses with an in-browser network simulator: IPv4 subnetting, switching and ARP, VLANs and trunks, static and OSPF routing, DHCP and DNS, access lists and NAT, each linked to the web-security courses.

## Interactive Tools & Sandboxes

- **Virtual Breadboard & Workbench**: Build and test circuits in real-time with virtual multimeters, oscilloscopes, and signal generators.
- **Interactive Code Editor & Runner**: Compile, upload, and debug embedded firmware directly in the browser.
- **Assessments & Verifiable Certificates**: Checkpoints, unit exams, and cryptographically verifiable PDF certificates upon passing course requirements.
